So I don't like this name, "special". What does "special" relativity mean? Einstein, in his first paper, uses a special change of coordinates, the Lorentz transformation, which had been derived earlier by Lorentz. Ten years later he understood that coordinates are really irrelevant, not so important (I don't know whether he understood this fully, deeply). Then he postulated that the laws of physics must be invariant with respect to any change, any arbitrary change, of coordinates, and he believed that from this assumption, this hypothesis, one can derive the equations of gravity. This was of course an error. It is impossible, because every description in terms of tensors is totally independent of the coordinates, and there are many, many possibilities. So it is trivial that physics must be coordinate-independent. But not everybody has the same opinion.

So I think that relativity theory is not about the transformation of coordinates; it is about relative velocity. [Reading the chat] "In our group … non-controversial?" Yes: boring, boring, boring. That is not science. So the main concept of relativity theory is relative velocity. And the principle of relativity is that all reference systems are on an equal footing, relative. There is no privileged reference system. This is what the theory of relativity is about. So "special" or "general": I don't think these are correct names.
