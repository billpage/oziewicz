All this says that to transform one reference system into another you must look only within the isometries, within the transformations that leave the metric invariant. So you must take the Poincaré group and see which element of the Poincaré group can do the transformation. Importantly, you have a pair of reference systems, and you must find the Lorentz transformation. The Lorentz transformation has no a priori information about relative velocity; it has information only about the conservation of the metric. The metric has no information about relative velocity. The Lorentz transformation has six parameters, and you must select a rotation and a boost. But how do you select? There is no unique way to select. All books say that there is a standard factorization, but there is no standard factorization. You must choose a preferred reference system, and then you get the relative velocity of this pair of reference systems. So in order to have one relative velocity in Einstein's theory of relativity, you need three reference systems: you need the systems A and B, and this preferred system here, which is an aether. Without an aether you do not have a velocity between two reference systems. Shocking, when I understood this.
